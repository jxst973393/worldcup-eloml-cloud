## 严格模型

采用 ModelOriented/EloML 原生流程：

```r
calculate_epp(
  elo_data,
  decreasing_metric = TRUE,
  compare_in_round = TRUE,
  estimation = "glmnet"
)
calculate_probability(epp_a, epp_b)
```

每场比赛转换为两行：胜 1、平 0.5、负 0。同场两队使用同一个 round。训练截止日期必须早于目标比赛日期。

EloML 二元概率回答“只在两队之间比较相对强度时谁更强”，不表示正式的 90 分钟胜平负概率。

Poisson 扩展层分别拟合主队/第一队和客队/第二队进球：

- `home_score ~ epp_diff + neutral_factor`
- `away_score ~ epp_diff + neutral_factor`

中立场比赛必须传入 `neutral=true`。

## 市场数据

把盘口视为市场预期和信息聚合信号，不把它当作事实。至少记录：

- 来源和抓取时间；
- 90 分钟 1X2；
- 亚洲让球档位及两侧水位；
- 大小球档位及两侧水位；
- 晋级盘与 90 分钟盘的区别；
- 阵容消息是否已官方确认。

不同来源的赔率有差异时给区间，不伪造统一精确值。优先赛事官方、主流体育媒体和可显示当前数值的赔率聚合页。

## 冲突处理

按以下优先顺序判断：

1. 已确认的重大阵容变化、红牌或实时比赛状态；
2. 严格 EloML 和 Poisson 的一致方向；
3. 让球档位是否发生真实升降；
4. 1X2 与让球水位是否同步；
5. 大小球对比分分布的校准；
6. 单一媒体观点或公众热度。

关键规则：

- 平手或浅让 0/0.5 只代表轻微市场优势，不能覆盖方向相反且差距明显的 EloML。
- 热门方赔率下降但始终升不了盘，可能只是表面热度。
- 让球从 0/0.5 升到 0.5，同时热门方水位和 1X2 持续下降，才是较完整的增强信号。
- 受让方低水、热门方高水通常说明市场对热门方穿盘信心有限。
- 模型与市场冲突时输出“分歧”，给概率区间，不强行写成确定结论。

建议综合时以模型为底座：模型和 Poisson 合计约 55%-65%，盘口与赔率约 20%-30%，大小球约 10%，阵容约 10%-15%。这只是解释框架，不要机械计算伪精确概率；重大阵容信息可以临时提高权重。

## 比分校准

- 先给 Poisson 原始 Top 3，不因主观判断改写排序。
- 大小球强压 2.5 小球时，提高 0-0、1-0、0-1、1-1的解释权重。
- 总盘升到 2.75 或 3 且大球水位持续下降时，提高 2-1、1-2、2-2等开放比分。
- 早球会改变淘汰赛结构：领先方可收缩，落后方压上，第二球概率上升。
- 给三个核心比分，再给 2-3 个“可能意外”，并说明触发条件。

## 已验证修正

法国对西班牙的赛前分析曾让浅盘市场信号覆盖 EloML：市场轻微偏法国，但严格 EloML 偏西班牙；实际西班牙 2-0获胜。复盘后的固定修正是：

- 不再把浅盘热门自动解释为实力优势；
- 盘口升不上去时保留模型反向结论；
- 2.5球附近不能只保留1-0和1-1，也要保留强队0-1、0-2路径；
- 先发进球会放大控球、反击和追分结构，临场应重新分配比分概率。

该案例用于校准方法，不得据此断言每个浅盘热门都会失利。

## 置信度

- 高：模型、Poisson、真实升盘、大小球和阵容大体一致。
- 中：模型与市场轻微冲突，但盘口变化有合理解释。
- 低：模型与市场正面冲突、阵容未确认或数据源明显滞后。

结论使用“略优、偏向、权重更高、需要防范”等措辞，避免“稳、必胜、锁定”。
