# 俱乐部模型与联赛修正规则

## 四层必须分开

1. **严格 EloML**：调用 GitHub 项目的 `calculate_epp()` 与 `calculate_probability()`，只回答两队二元相对强弱，不含平局、不预测比分。
2. **俱乐部比分层**：按同一联赛历史赛果拟合时间加权的主客场攻防 Poisson，并用 Dixon-Coles 修正 0-0、1-0、0-1、1-1。
3. **市场层**：将 1X2 和大小球十进制赔率先去水，再与比分层按明确权重校准。市场结果不得冒充严格 EloML。
4. **信息层**：伤停、首发、赛程密度、欧战、旅行、换帅和天气只在有来源时修正结论与置信度。

训练截止必须早于目标比赛日期。不同联赛分别拟合，不把英超、西甲数据拼成一个共同进球基线。

## 为什么联赛版不同

- 俱乐部主客场长期稳定存在，必须显式估计主场项；世界杯中立场逻辑不适用。
- 转会、换帅和升降级使俱乐部变化更快，比分层使用 240 天半衰期，而严格 EloML 保持项目原生流程。
- 联赛平局直接计入 90 分钟结果，不计算“晋级概率”。杯赛若有加时或点球，必须切换到杯赛说明。
- 密集赛程和欧战轮换是五大联赛常见变量，确认首发后可明显改变进球均值和置信度。

## 英超与西甲优先规则

**英超**

- 节奏、转换和定位球更容易放大尾部比分；总进球盘升高且双方后场不整时，不要只保留 1-0、1-1。
- 圣诞/新年密集赛程、连续客场及欧战后 72-96 小时恢复尤其重要。
- 强队主场深盘若持续退盘，同时 1X2 没有同步支持，应降低大胜与穿盘叙述的置信度。

**西甲**

- 控球优势不能自动等同于高质量机会；结合禁区触球、射正和对手低位防守能力。
- 中下游比赛常受比赛节奏和先开纪录影响，盘口浅且总盘偏低时保留平局与 1 球差路径。
- 强队遇到欧战轮换或客场高压能力下降时，优先修正进球分布，不直接删除严格 EloML 方向。

这些是校准检查项，不是固定加减分公式；没有可核实信息时不使用。

## 升班马和赛季切换

- 球队在训练样本少于 20 场时标记低样本，不给高置信度。
- 新赛季前 5 轮提高市场与阵容信息的重要性，但市场权重仍不得超过 0.5。
- 大规模转会、主教练更替或战术体系变化时，降低历史模型置信度。
- 五大联赛之外的上赛季数据不能直接混入同一比分模型；若要纳入，必须另做联赛强度换算并清楚说明。

### 升班马市场回退

目标球队不在所选顶级联赛训练样本中时，按以下边界处理：

1. 原生严格 EloML 和同联赛 Poisson/Dixon-Coles 均写“不可用”，保留脚本错误作为审计信息。
2. 不使用十多年前的顶级联赛赛果，也不把低级别原始进球率直接当作顶级联赛进球率。
3. 赛程须由赛事官方与俱乐部官方或另一可靠来源交叉确认。
4. 市场回退至少需要两个当前公开市场来源。其中一个必须提供同一时点、同一家机构的完整 1X2 和 2.5 大小球数值；第二个用于确认方向与盘位，不能把各家的最高赔率拼成无水套利组合。
5. 满足第 3、4 项后，运行 `scripts/predict-market-score.sh`。其独立 Poisson 只拟合去水后的 1X2 与大小球，Top 3 必须来自该矩阵。
6. 输出名称固定为“市场校准比分层”或“市场独立 Poisson 回退”。不得写成严格 EloML、俱乐部比分层或综合模型；阵容和升班马信息只解释置信度，不冒充历史训练样本。
7. 如果缺少完整赔率、时间戳或第二来源，只输出已核实事实并停止，不生成概率和比分。

外部 Opta、Club Elo、上赛季低级别表现可作为独立方向验证，但必须标注来源，不能替代缺失的原生层。

### 联网接口失败时的核验

- 浏览/搜索工具返回 `401 Unauthorized` 或 `403 Forbidden`，只代表该接口不可用，不代表目标公开网页不存在。
- Agent internet access 已开启时，使用带普通浏览器 User-Agent 的 HTTPS 命令行请求，并优先解析静态官方新闻、JSON-LD、公开赔率聚合页和其公开异步接口。
- 英超市场优先运行 `fetch-oddstorm-market.py` 与 `fetch-betexplorer-market.py`。两者分别抓取独立站点，并输出机构、赔率、原始页面和 UTC 抓取时间。
- OddStorm用于取得同一家机构的完整1X2、2.5大小球和亚洲主盘；BetExplorer用于第二来源交叉核验1X2和2.5大小球。
- 两个来源的胜平负方向一致即可继续。数值存在正常机构差异时使用第一来源的同机构完整快照拟合，并把差异写入置信度；不要混拼各站最高赔率。
- 命令行也无法取得完整数据时才按“当前数据不足”停止。

## 市场去水与冲突

三项十进制赔率按 `q_i = (1 / odds_i) / sum(1 / odds)` 去水。大小球两项同理。

综合概率是透明校准，不是真实概率：

`综合 = (1 - w) × 比分层 + w × 去水市场`

- 常规赛前 `w=0.20-0.30`。
- 阵容未确认、来源不一致或盘口快速摆动时 `w=0.10-0.20`。
- 官方首发已出且多个来源一致时最多 `w=0.35-0.40`。
- 不允许为了迎合盘口临时调权重，也不允许超过 `0.5`。

模型与市场冲突时写“分歧”：

- EloML 强弱与比分层一致，但仅有浅盘反向：保留模型方向，降低置信度。
- 让球真实跨档、1X2 同步、大小球和阵容也支持反向：综合层可以改变方向，但必须保留原始模型数值。
- 只有同盘水位小幅变化：不得称为方向翻转。

## 比分和意外路径

- 三个核心比分来自校准后的比分矩阵，不手工排列。
- 大小球只校准总进球分布，不能单独决定胜负方向。
- 可能意外至少覆盖一种反向结果或高比分尾部，并给出触发条件，如早球、红牌、轮换失效或定位球失守。
- 单个最高概率比分与胜平负总概率可能不同，这是多个比分聚合后的正常现象。

## 复盘指标

不要只问“猜中没有”。至少记录：

- 90 分钟胜平负是否命中；
- Brier score 或 log loss；
- Top 3 比分是否覆盖；
- 总进球方向是否正确；
- 模型、市场和阵容中哪一层导致偏差；
- 是否发生红牌、点球、早球或极端射门转化率。

累计 50 场以上再调整半衰期或市场权重，避免被一两场结果带偏。
