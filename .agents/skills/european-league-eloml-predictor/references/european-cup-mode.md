# 欧洲俱乐部杯赛模式

仅用于欧冠、欧联、欧协联及其资格赛。它是
`european-league-eloml-predictor` 内的隔离模式，不改变五大联赛模型，也不使用世界杯数据。

## 模型边界

- 先确认赛事、轮次、冠军路径/联赛路径、首回合/次回合/单场制及晋级规则。
- `scripts/predict-league-match.sh` 的同联赛进球基线不能直接用于跨联赛杯赛。
- 只有取得足够且可比的俱乐部正式赛样本时，才运行原生 EloML；否则保留“严格强度方向”，不输出伪精确的严格 EloML 概率。
- 外部 Club Elo、UEFA 系数或球队身价只能标注为外部强度参考，不得称为 ModelOriented/EloML 原生结果。
- 90 分钟比分层、晋级概率和市场概率始终分开。加时与点球不计入 90 分钟比分。

## 赛前流程

1. 从 UEFA 或赛事官方来源确认比赛和阶段，至少再用一个可靠来源核对开球时间、场地与阵容信息。
2. 收集双方最近正式赛，优先级为：本届欧战、国内联赛/杯赛、上赛季欧战。友谊赛只作阵容状态旁证。
3. 检查跨联赛强度、主场是否为临时场地、旅行、休息天数、新帅、新援磨合、伤停、停赛和注册资格。
4. 核实同一时间点的 1X2、亚洲让球和大小球。赔率先去水；无法取得同源亚洲盘时，只能写“由 1X2 映射的让球区间”，不能冒充实时报价。
5. 用独立 Poisson 比分层拟合或校准总进球和双方进球均值。若主要由市场反推，必须写“市场校准比分层”，不得称为严格 EloML 比分。
6. 输出三个最高权重比分、一个反向意外比分及触发条件。

## 两回合修正

**首回合**

- 一球领先后通常降低冒险程度，深让穿盘概率不能只按纸面强弱外推。
- 客队保平意愿和次回合主场会提高 0-0、1-1、1 球差的权重。
- 若强队阵容刚重组或尚未进入联赛节奏，降低大胜置信度。

**次回合**

- 先写首回合比分和总比分，再按晋级需求修正节奏。
- 落后方必须追分时提高后半场进球和高比分尾部；领先方反击效率决定比分是否被拉大。
- “90 分钟胜负”和“最终晋级”分别输出，不能混成一个概率。

## 走地更新

- 未开赛时没有真实走地数据，只能列观察条件。
- 开赛后先核实分钟、比分、红牌、射门、射正、高质量机会、角球和实时盘口时间戳。
- 只有控球而缺少禁区触球与射正时，不提高热门方大胜权重。
- 早球、红牌、门将伤退或连续高质量机会可以重建比分分布；赛前概率只作先验。

## 复盘与更新

- 将每次正式赛前版本和赛果追加到 `data/evaluations/european-cup-predictions.csv`。
- 至少记录胜平负、Top 3 比分、大小球、意外事件和信息时间戳。
- 单场命中只记录，不调权重。累计至少 50 场后再比较 Brier score、log loss、Top 3 覆盖率和大小球准确率。
- 不用赛后结果倒推“盘口早已预示”，也不覆盖原始赛前结论。
